PROJECT ARCHITECTURE

Sensor → ESP32 → Wi-Fi → ThingSpeak → Dashboard

DHT22 measures temperature and humidity. The simulated gas sensor provides an analog value. ESP32 processes the readings, drives the OLED and alert LED, and uploads four fields to ThingSpeak.
